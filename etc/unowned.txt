# Baseline: /etc files owned by no package.
#
# Produced by diffing `find /etc -type f` against every path in `pacman -Ql`.
# bash/config-drift diffs the live sweep against this file after every sysup; a
# path that appears here has been looked at and decided about, and anything NOT
# here is a finding that needs a decision. Accepting a new one means adding the
# line in a commit whose message says why.
#
# The raw sweep returns 172 paths, of which 131 are /etc/ca-certificates/
# {extracted,trust-source}/ -- regenerated wholesale by update-ca-trust, so they
# churn on every ca-certificates update and would make this file wallpaper.
# config-drift excludes those two trees; do not add them here.
#

# --- mirrorlist rollback copy -------------------------------------------------
# Written by bash/mirrorlist-rank --install before it replaces the mirrorlist: the
# only way back if a re-rank installs a bad list, since no pacman-mirrorlist
# package sits in the cache to extract one from. Inert -- pacman.conf Includes the
# literal mirrorlist path, not a glob, so it is never read as extra mirrors.
#
# Transient by nature: it appears at each --install and can be deleted once the
# new list is trusted. Listed here so that it does not read as a new finding
# every time it comes back; config-drift checks /etc for additions, so the entry
# costs nothing while the file is absent.
