## The through-line: verify with a control

The single most useful habit this audit established. Repeatedly, a check "passed" only
because it *couldn't fail*:

- The starship config check reported no unknown keys — until a deliberately invented
  `[zzz_not_a_module]` was also accepted, proving starship silently ignores unknown
  modules and the check had no power. Replaced with a comparison against
  `starship module --list`.
- A `yt-dlp` option scan flagged three valid options as unknown, because the regex
  required options to start a line and so missed every option with a short alias
  (`-c, --continue`).
- `grep -c` returning 1 on zero matches tripped `|| echo` fallbacks twice, printing
  bogus values.
- `ls a b` with one path missing tripped a `||` and reported "no config file anywhere"
  about a file that existed.
- `sudo -n docker images` couldn't authenticate, returned nothing, and got read as
  "zero images". True, but for the wrong reason — confirmed instead via
  `/var/lib/docker` being 0 bytes.

**Establish that a check can detect absence before trusting a negative result.**

## Findings that were real

### Silent breakage

- **`fix-wifi.sh` was load-bearing and untracked.** A hand-installed root hook cycling
  `ath11k_pci` around suspend; the Qualcomm QCNFA765 does not reliably re-associate
  without it. Owned by no package, absent from this repo — a fresh `install-root.sh`
  would have dropped it and left WiFi dead after every resume. Now tracked, both hooks
  installed by one idempotent loop.
- **`~/.local/bin/sioyek` was a 3-line wrapper, not the binary.** Forces
  `QT_QPA_PLATFORM=wayland`; without it sioyek falls back to XWayland. Also untracked.
- **rclone was failing silently.** No `OnFailure`, no retry ceiling. Now notifies via
  `notify-failure@` *and* appends to `~/.local/state/service-failures/failures.log` —
  a popup is useless if nobody is at the machine.
- **`install.sh` created the vim symlink before `~/.config` existed**, so a fresh machine
  failed at that step.
- **`xdg-user-dirs-update` clobbered the tracked `user-dirs.dirs` symlink** on a fresh
  login; the service is now masked.

### Config that never did anything

- **`gtk-3.0/settings.ini` and `gtk-4.0/settings.ini` were inert.** GTK appearance comes
  from dconf via the `xdg-desktop-portal` Settings interface, which overrides
  `settings.ini` for every key it serves. A commit intending `Noto Sans 11` had never
  taken effect — GTK apps render in `Adwaita Sans 11`. Both files removed; dconf
  documented as the real source.
- Vim's clipboard mappings never worked: the build is `-clipboard`, so `"+`/`"*` do not
  exist. Replaced with `\y`/`\P` piping to `wl-copy`/`wl-paste`.
- 7 dead tmux bindings, 7 invalid lazygit keys, 3 undefined git aliases, a `batt` awk
  divide-by-zero, `:ALEFix` erroring on every YAML/JSON save.

### Package-level

- **`aocl-gcc` (686 MiB) is load-bearing** despite `Required By: None` — C++ projects link
  `-lblas`/`-llapack`, which resolve to AOCL. Second-checked: libFLAME exports 12,161
  symbols with 0 of 30 common LAPACK routines missing; `dgemm`/`dgesv`/`dsyev` exact.
- **`PKG_CONFIG_PATH` must not be set globally.** AOCL's pkgconfig dir also holds
  `fftw3*.pc`, and pkg-config searches `PKG_CONFIG_PATH` *before* its compiled-in
  defaults — so exposing it makes `pkg-config fftw3` return AOCL's 3.3.10 while the
  system's 3.3.11 gets loaded at runtime (same soname). Per-project only.
- **Don't wrap BLAS calls in your own `omp parallel`.** `omp_max_active_levels` is 1 by
  default, so BLIS collapses to one thread inside an active region. Measured on
  4×1500³ dgemm: **435 GFLOP/s** letting BLIS thread vs **265** hand-parallelised over 4
  OpenMP threads. No oversubscription — just a 1.65× loss.
- `BLIS_NUM_THREADS` outranks `OMP_NUM_THREADS`, so setting the latter for your own
  parallel regions will not resize BLIS.
- **Tor Browser is deliberately unconfigured.** Its anonymity depends on every user
  looking identical, so a `user.js` or `userChrome.css` makes you *more* fingerprintable.
  Recorded in `CLAUDE.md` so a future audit doesn't offer to theme it.
- Removed: 370 MB orphaned `torbrowser-launcher` data, 15 MB unused fonts, ~7,000 lines of
  dead `zsh/archive` + `tmux/layouts/archive`.

## sioyek → papis → pask notes (new feature)

Built this session, both halves.

**Capture** (`dotfiles`): `Alt+n` → `bash/sioyek-papis-note` appends a page heading, the
selection, and sioyek's page/offset to the document's papis `notes.md`, then opens it in
nvim. The papis document is found from `%{file_path}`'s directory via
`papis edit --doc-folder`, and the note is created with `--notes --editor true` — a no-op
editor — so **papis writes the `notes:` key itself** and this repo never edits
`info.yaml`. Once the note exists both papis calls are skipped.

**Ingestion** (`papis-ask`, stage 4): notes are embedded with quotes stripped, cited as
`@ref (note)`, and chunked by `ask.chunk-chars`.

Three findings, each of which would have failed quietly:

1. **An uncommented capture is heading + quote.** Stripping quotes leaves `## p.3`, so the
   obvious implementation embeds a vector whose entire content is a page number — on every
   single capture. `indexable_prose()` skips a note unless some line is not a heading.
2. **The staleness gate read `chunk_source == "pypdf"`.** Notes are split by the same
   settings, so a `chunk-chars` change would have left every note chunked at whatever was
   configured the day it was written, with no mtime moving to reveal it.
3. **The `(note)` marker was overwritten and unread.** `update_index_metadata` lists
   `citation` in `fields_to_overwrite_from_metadata`, so the DocDetails upgrade replaced
   it with the papis title — and rendering never read `citation` anyway, building from
   `doc.other["ref"]`. A note cited as `[@Kalman_1960]`, identical to its paper. The marker
   now lives in `output.source_ref`. **Only live validation caught this**; no unit test
   looked at `citation`.

Why quotes are stripped: the passage is already embedded from the PDF, so indexing it
again makes one paragraph compete with itself for `ask.max-sources` — a question returns
two copies of it and one fewer other paper.

Sandbox: `~/learning/playground/sioyek-papis-notes/` — 17 checks, `PAPIS_LIB` isolation so
the real library is untouched, `bash run.sh --live` for the paid path.
